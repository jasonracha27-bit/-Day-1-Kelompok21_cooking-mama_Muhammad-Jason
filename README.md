-Konteks merupakan salah satu hal penting dalam memberikan perintah atau prompt kepada AI agar hasil yang diberikan lebih sesuai dengan kebutuhan.
-Penggunaan prompt yang disertai konteks biasanya dapat menghasilkan jawaban yang lebih tepat dibandingkan prompt yang hanya berisi perintah singkat tanpa penjelasan tambahan.
-Jika prompt yang diberikan kurang jelas atau tidak memiliki konteks yang cukup, hasil dari AI bisa saja tidak sesuai dengan apa yang diharapkan.
-Dalam membuat prompt yang baik, terdapat empat bagian utama yang bisa digunakan, yaitu role (peran), task (tugas), context (konteks), dan format (bentuk hasil yang diinginkan).
-Membuat prompt membutuhkan proses percobaan dan perbaikan secara bertahap. Jika hasil pertama belum sesuai, kita bisa mengubah atau menambahkan instruksi sampai mendapatkan jawaban yang diinginkan.
-AI tidak selalu memiliki akses terhadap seluruh riwayat percakapan sebelumnya, sehingga konteks dan informasi penting sebaiknya disampaikan kembali ketika diperlukan.
-Beberapa manfaat dari prompt engineering adalah membantu meningkatkan kualitas jawaban AI, mengurangi kemungkinan munculnya respons yang bias atau kurang pantas, membuat hasil lebih mudah dikontrol, serta memberikan pengalaman penggunaan yang lebih baik.

Materi Git

  Git merupakan sebuah sistem pengelola versi (Version Control System) yang digunakan untuk mencatat setiap perubahan pada file. Dengan Git, kita bisa mengetahui siapa yang melakukan perubahan, kapan perubahan dilakukan, dan bagian apa saja yang diubah.

  Git pertama kali dikembangkan oleh Linus Torvalds pada tahun 2005 untuk membantu proses pengelolaan kode dalam pengembangan perangkat lunak.

  Dalam Git terdapat tiga area kerja utama, yaitu:
  
- Working Directory: Tempat kita membuat, mengedit, atau menghapus file dalam sebuah proyek.
- Staging Area: Tempat untuk menyiapkan perubahan yang ingin disimpan sebelum dimasukkan ke dalam repository.
- Git Directory (Repository): Tempat Git menyimpan riwayat perubahan atau versi file yang sudah disimpan (commit).
